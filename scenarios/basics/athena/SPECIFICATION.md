# Amazon Athena Basics Specification

This specification describes a Basics scenario for Amazon Athena that demonstrates how to interact with the Amazon Athena service using an AWS SDK. This is a DRAFT specification generated by the SpecGen tool and should be reviewed for accuracy before implementation.

The scenario demonstrates a complete workflow: creating a workgroup, running SQL queries against data in Amazon S3 (creating a database, creating a table, querying data), managing named queries, reviewing query execution history, and cleaning up all resources. It showcases Athena's serverless interactive query capabilities with standard SQL.

### Resources

The scenario requires the following prerequisite resources created via AWS CloudFormation (since they belong to different AWS services):

- **Amazon S3 Bucket**: An S3 bucket to store query results and sample data. The bucket is used as the output location for Athena query results and to host a small sample CSV dataset for querying.

The CloudFormation template should:
- Create an S3 bucket with a unique name (e.g., using the stack name as a prefix)
- Upload a small sample CSV dataset as an S3 object (or the scenario can use a DDL-only approach with inline data via `VALUES` or `CTAS`)
- Output the bucket name and ARN for use by the scenario

**Alternative (simpler approach):** The scenario can avoid uploading sample data by using Athena's ability to query inline data with `SELECT ... UNION ALL` or by creating a table with `CTAS` (Create Table As Select) using generated data. This avoids the need for a pre-existing dataset in S3.

### API Actions Used

- [CreateWorkGroup](https://docs.aws.amazon.com/athena/latest/APIReference/API_CreateWorkGroup.html) — Creates a workgroup with a specified name and configuration, including the S3 output location for query results.
- [GetWorkGroup](https://docs.aws.amazon.com/athena/latest/APIReference/API_GetWorkGroup.html) — Returns information about the workgroup with the specified name, including its configuration and state.
- [StartQueryExecution](https://docs.aws.amazon.com/athena/latest/APIReference/API_StartQueryExecution.html) — Runs SQL query statements. Used for DDL (CREATE DATABASE, CREATE TABLE) and DML (SELECT) queries.
- [GetQueryExecution](https://docs.aws.amazon.com/athena/latest/APIReference/API_GetQueryExecution.html) — Returns information about a single query execution, including status (QUEUED, RUNNING, SUCCEEDED, FAILED, CANCELLED).
- [GetQueryResults](https://docs.aws.amazon.com/athena/latest/APIReference/API_GetQueryResults.html) — Streams the results of a completed query execution from the Athena query results location in Amazon S3.
- [ListQueryExecutions](https://docs.aws.amazon.com/athena/latest/APIReference/API_ListQueryExecutions.html) — Provides a list of available query execution IDs for queries run in the specified workgroup. Supports pagination.
- [CreateNamedQuery](https://docs.aws.amazon.com/athena/latest/APIReference/API_CreateNamedQuery.html) — Creates a named (saved) query in the specified workgroup for reuse.
- [ListNamedQueries](https://docs.aws.amazon.com/athena/latest/APIReference/API_ListNamedQueries.html) — Provides a list of named query IDs saved in the specified workgroup. Supports pagination.
- [DeleteNamedQuery](https://docs.aws.amazon.com/athena/latest/APIReference/API_DeleteNamedQuery.html) — Deletes a named query by ID.
- [DeleteWorkGroup](https://docs.aws.amazon.com/athena/latest/APIReference/API_DeleteWorkGroup.html) — Deletes the workgroup with the specified name. Supports recursive delete of contained resources.

## Hello Athena

The Hello Athena example is a minimal, standalone runnable program that verifies connectivity to the Amazon Athena service.

- Create an Athena client.
- Call `ListWorkGroups` to retrieve a list of workgroups in the account.
- Display the names and states of the returned workgroups.
- The primary workgroup always exists and should appear in the results.

**Expected output:**
```
Listing Athena workgroups...
Workgroup: primary (State: ENABLED)
Found 1 workgroup(s).
```
